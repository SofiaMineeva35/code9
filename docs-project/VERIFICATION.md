# Реально выполненные проверки

Проверено 25 октября 2026, Chromium 151, локальная production-сборка и публичный сайт GitHub Pages. Все данные учебные.

- `npm test`: проверки обязательных полей, контактов, опасной/неполной ссылки, расширений и размера, общей модели черновика, защиты ручной правки, состава итоговых данных.
- `npm run test:browser`: оба брифа и завершения; шаги вперёд/назад и «Изменить ответ»; «Пока не знаю»; три канала и сохранение значений; пустые поля и неверная почта; ссылка; добавление/удаление файлов, ZIP, файл больше 20 МБ, лимит 5; перезагрузка сохраняет текст и предупреждает о повторном добавлении файлов; политика не сбрасывает ответы; удаление контекста PowerDot.
- Проверены ширины 320, 390, 768 и 1440 px, без горизонтальной прокрутки. Скриншоты телефона и компьютера просмотрены. Поле краткого брифа на 1440 px: ширина 800, отступ слева 48, верх примерно 444 px; логотип 180×44 — соответствует исходному экрану S01.
- Клавиатура: стрелки выбирают ответ, Space меняет согласие; видимый фокус измерен, новый шаг фокусирует заголовок. У полей постоянные подписи, ошибки связаны через `aria-describedby`, сообщения объявляются через `alert`/`status`.
- Консоль основного полного сценария: 0 ошибок. Запросы ресурсов основного сценария: 0 HTTP-ошибок.
- Скачаны PDF краткого и интерактивного брифов; русский текст извлечён через pypdf и проверен, включая контакт, имя компании и русское имя файла. Длинный PDF — 5 страниц; все 140 строк с «Ёж» присутствуют. Рендер интерактивного PDF просмотрен: читаемый текст, без квадратиков и обрезки.
- `tests/edge-cases.cjs`: в тестовом браузере искусственно вызваны зависшее/ошибочное чтение файла, отказ загрузки шрифта PDF и запрет sessionStorage. Проверены отмена, повтор чтения, повтор PDF без повторной обработки и предупреждение о хранилище. Ошибки сети в этом отдельном тесте ожидаемы, намеренно вызваны тестом.
- `npm run build`: production-сборка успешна. Есть предупреждение Webpack о размере отложенного модуля jsPDF (~395 КБ). Он загружается после завершения, основной JS брифа ~221 КБ. HTML-рендер и canvas для PDF не используются.
- `npm start`: dev server успешно запущен на 127.0.0.1:8080, страница ответила HTTP 200.
- После обновления зависимостей npm сообщил 0 уязвимостей.

Статические SVG проверены: локальные файлы непустые; логотип в шапке, значки 20×20 в вариантах, галочка 24×24 в согласии. Загружается локальный IBM Plex Mono, цвета `#f6f6f4`, `#0c0c0c`, `#bfbfba`, ошибка `#9e1f1a`. При проверке исправлено положение флажка на телефоне. Дизайн не заменялся; под формой добавлено только необходимое уведомление об учебной обработке, а результат переименован, чтобы не сообщать о несуществующей доставке.

Не выполнены и не заявляются: тест на физическом телефоне, Safari/Firefox, проверка реальной доставки/загрузки на сервер, HTTP 429/таймауты настоящего API, отправка писем, полный аудит соответствия WCAG. Эти проверки требуют устройств или отсутствующего сервера. Статус публичной страницы — в DELIVERY.md.
