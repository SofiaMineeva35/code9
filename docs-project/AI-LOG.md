| --- | --- | --- | --- |
| Изучить Figma и проект | По ссылке секция с 20 экранами, состояниями элементов и блоком PDF. Ответ секции содержит только структуру | Запросили подробное оформление отдельных экранов S01, I01, I03, I04, I06, I07, R02, R06, A02 и элементов формы. Figma не редактировали | Получили контекст дизайна и изображения; сопоставили размеры и тексты |
| Сохранить существующую работу и собрать Webpack | В старой учебной странице неверный путь импорта, `eexport` и `girElementById`; сборка прерывалась | Исправили три опечатки, сохранили страницу `rps-react.html` | Повторная production-сборка и запуск dev server |
| Реализовать сохранение и переключение | Пересборка краткого описания при каждом переключении могла уничтожить ручную правку | Отдельные ответы шагов, краткий текст и признак `shortEdited` | Модульный тест и браузер: правка краткого текста → другой вариант → возврат |
| Реализовать доступное согласие и адаптацию | Автотест обнаружил, что декоративный значок перекрывает флажок; при просмотре телефона после изменения CSS знак потерял размер | Убрали перехват указателя у значка, явно закрепили размер 24×24 и положение отдельно от текста | Повторный сценарий мышью и Space; измерение значка и финальный скриншот телефона |
| Подготовить PDF с русским текстом | Без встроенного шрифта кириллица ненадёжна; длинный текст требует новых страниц | Использовали настоящий IBM Plex Mono, встроили TTF в PDF, добавили построчный перенос и новые страницы | Скачали краткую, интерактивную и длинную копии; извлекли русский текст, проверили все 140 повторов тестовой строки; длинная копия — 5 страниц; просмотрели рендер |
| Обеспечить результат без выдуманной доставки | В проекте нет API и почтовой интеграции | Учебный результат «Бриф подготовлен», явные подписи в интерфейсе и PDF, повтор PDF отдельно от обработки | Оба завершения в Chromium; искусственный отказ загрузки шрифта → ошибка PDF → повтор → скачивание |
| Проверить инструменты перед публикацией | npm сообщил о 35 уязвимостях исходного дерева зависимостей | Совместимые исправления и обновление css-minimizer-webpack-plugin и webpack-dev-server; один менеджер пакетов npm | Установка сообщила 0 уязвимостей; сборка и dev server после обновления |

Impeccable: прочитаны инструкции переноса и проверки качества. Вспомогательный `impeccable context` не запустился из-за отсутствующего движка и ограничения записи в кеш. Автоматический отчёт Impeccable не получен; доступность, адаптивность и оформление проверялись напрямую по его рекомендациям, сохраняя дизайн Figma.
