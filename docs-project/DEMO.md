# Демонстрация за 2–3 минуты

1. Откройте главную страницу. Покажите краткий бриф и нажмите «Отправить запрос» с пустыми полями: появятся ошибки, фокус перейдёт к описанию.
2. Откройте «Интерактивный бриф». Выберите «Есть идея нового продукта», допишите «Учебное приложение для сотрудников». Покажите, как выделился ответ и стала доступна кнопка «Дальше».
3. На втором шаге выберите «Пока не знаю»: появляется пояснение из макета. Затем выберите «Упростить работу команды» и напишите «Задания и фотографии результата в одном месте».
4. Вернитесь «Назад»: первый ответ сохранён. Дойдите до проверки; «Изменить ответ» возвращает к нужному вопросу.
5. Переключитесь в краткий бриф: ответы собраны в описание. Измените текст, переключитесь туда и обратно: ручная правка сохранена, ответы по шагам тоже.
6. Укажите anna@example.com, имя «Анна Тестовая». Прикрепите учебный TXT, удалите и добавьте снова. Покажите ошибку на ZIP. Удалите ошибочный файл. Добавьте https://example.com/brief.
7. Отметьте согласие. Нажмите «Отправить запрос»: покажите честное уведомление об учебном режиме, результат и скачайте PDF. В PDF есть русские ответы, контакт и имя файла; письма не отправляются.

Как объяснить код: «При выборе ответа обработчик записывает текст в `draft.existing`. React видит новое состояние и обновляет выделение ответа и кнопку. Эффект сохраняет черновик в текущей вкладке. При переходе назад меняется номер шага, сами ответы остаются».
