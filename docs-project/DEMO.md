# Демонстрация V5 за 2–3 минуты

1. Откройте краткий бриф. Нажмите «Подготовить бриф» с пустыми полями: появятся ошибки, фокус перейдёт к описанию.
2. Откройте «Интерактивный бриф». Выберите «Есть идея нового продукта», допишите «Учебное приложение для сотрудников». Ответ выделится, кнопка «Далее» станет доступной.
3. Нажмите «Далее», выберите «Упростить работу команды». Вернитесь «Назад»: первый ответ сохранён, положение кнопок не меняется.
4. Дойдите до проверки. Нажмите «Изменить исходные данные», измените ответ, затем «Сохранить ответ»: сразу откроется проверка запроса.
5. Переключитесь в краткий бриф: ответы собраны в описание. Измените текст, переключитесь туда и обратно: ручная правка сохранена.
6. Укажите anna@example.com, имя «Анна Тестовая». Прикрепите учебный TXT, удалите и добавьте снова. Покажите ошибку на ZIP и удалите его. Добавьте https://example.com/brief.
7. Отметьте согласие и нажмите «Подготовить бриф». В результате нет переключателя режимов. Скачайте PDF: в нём русские ответы, контакт, имя и размер файла. Запрос и письмо не отправляются.
8. Перезагрузите страницу: результат восстановится. Нажмите «Начать новое обращение»: откроется пустой бриф.

Как объяснить код: «При выборе ответа обработчик записывает текст в draft.existing. React получает новое состояние, обновляет выделение ответа и доступность кнопки. Эффект сохраняет черновик в текущей вкладке. При переходе назад меняется номер шага, сами ответы остаются».
